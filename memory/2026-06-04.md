### bash 避坑
- $符号在 cmd 的 `for /f` 里可以，但 Python 子进程读 stdout 要注意 GBK 编码
- 每次改代码后要检查编译：`py -c "compile(open('path').read(),'x','exec'); print('OK')"`
- `sys.stdout.reconfigure(encoding='utf-8')` 在 Windows 上可能不可靠，需要加 `errors='replace'`
