# 2026-05-02 大虾日记

## 评估 GenericAgent
- 老大发了 https://github.com/lsdefine/GenericAgent 让看值不值得装
- ~3K 行极简 Agent 框架，9个原子工具 + 100行 Agent Loop
- 核心卖点：自我进化 Skill 树 + 真浏览器注入(保留登录态) + ADB 控制安卓
- 和 Hermes 对比：架构哲学完全不同（极简自举 vs 全功能平台）
- GenericAgent 杀手锏：浏览器操控和手机 ADB，Hermes 没有这块
- 结论：能力互补，值得装来补浏览器/手机操控的短板
- 已 clone 到 D:\GenericAgent

## 踩坑：搞错 Hermes 定位
- 坑：我一直把 Hermes 当成 OpenClaw 的钉钉消息插件/中间件，以为它只是传话的
- 实际：Hermes 是和 OpenClaw 直接竞争的**完整独立 Agent 框架**
  - 有自己的独立机器人、持久记忆系统、用户画像
  - 40+ 工具 + MCP 扩展 + Skill Hub 公共市场 + agentskills.io 标准
  - 子 Agent 调度、并行工作流、FTS5 会话搜索
  - 多平台消息（Telegram/Discord/Slack/WhatsApp/Signal/钉钉）
  - 内置 cron 调度
  - 甚至有 `hermes claw migrate` 从 OpenClaw 一键迁移
- 教训：别凭印象下结论，先看代码和 README

## GenericAgent 配置模板要点
- mykey_template.py → 复制为 mykey.py 填 API Key
- 支持 NativeClaudeSession / NativeOAISession / MixinSession（故障转移）
- 支持 GLM-5.1 Anthropic 兼容端点（智谱）
- 钉钉前端：dingtalk_client_id / dingtalk_client_secret / dingtalk_allowed_users
- 最小依赖：pip install requests streamlit pywebview
