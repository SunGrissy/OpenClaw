## Multica 路由 Bug 根因分析（21:53 开始）
- **问题**：钉钉机器人同时配了 multica 和 Hermes，发"派单"时 multica 不接单、走到 Hermes
- **根因**：Hermes Gateway 的 dotenv 加载顺序导致路由变量丢失
  1. `load_hermes_dotenv` 先读 `HERMES_HOME/.env`（pm profile = `D:\hermes\pm\.env`），override=True
  2. `D:\hermes\pm\.env` 存在 → 项目 `.env` 用 override=False
  3. `D:\hermes\pm\.env` 里没有 `HERMES_INBOUND_ROUTER_ENABLED` 和 `HERMES_ROUTER_MULTICA_ENABLED`
  4. 系统环境变量/全局 `.env` 里的路由变量被覆盖为空 → 路由器不初始化
- **修法**：在 `D:\hermes\pm\.env` 末尾加 `HERMES_INBOUND_ROUTER_ENABLED=on` 和 `HERMES_ROUTER_MULTICA_ENABLED=on`
- **状态**：等老大确认再加
